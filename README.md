# 🌫️ Pearls AQI Predictor

> AI-powered Air Quality Index forecasting for **Lahore, Punjab, Pakistan** — 3-day predictions using a fully serverless ML pipeline.

---

## 🚀 Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
pip install -r requirements/requirements.txt
```

### 2. Set up environment variables
```bash
cp .env.example .env
# Edit .env and add your HOPSWORKS_API_KEY if using Hopsworks
```

### 3. Run the ML pipeline
```bash
python pipeline/feature_pipeline.py --upload
python pipeline/training_pipeline.py --register
```
This fetches live weather + air quality data, trains 3 models (Random Forest, Ridge, TensorFlow), picks the best one by RMSE, and exports `data/aqi_dashboard_data.json`.

### 4. Launch the Flask dashboard
```bash
python app/flask_api.py
```
Open **http://127.0.0.1:5000** in your browser.

## 📊 Frontends & API Endpoints

### Option A — `aqi/app.py` (fast, uses pre-generated data)  -  (optional)
```bash
python aqi/pipeline.py   # generates data/aqi_dashboard_data.json first
python aqi/app.py        # serves it at http://127.0.0.1:5000
```

| Endpoint | Description |
|----------|-------------|
| `GET /` | Dashboard UI |
| `GET /api/data` | Full dashboard JSON |
| `GET /api/forecast` | Hourly 72h forecast CSV as JSON |

---

### Option B — `app/flask_api.py` (live inference via `src/` pipeline)    (main-file)
```bash
python app/flask_api.py   # serves at http://127.0.0.1:5000
```
> Uses the already-trained model saved in `models/` to run live inference on every request. Falls back to `data/aqi_dashboard_data.json` automatically if no model file is found.

| Endpoint | Description |
|----------|-------------|
| `GET /` | Same dashboard UI |
| `GET /api/data` | Live dashboard JSON (runs model inference) |
| `GET /api/forecast?days=3` | Live 72h forecast |
| `GET /api/current` | Current AQI + alert status |
| `GET /api/metrics` | Training RMSE for all evaluated models |
| `GET /health` | Health check |

## 🔄 CI/CD Automation (GitHub Actions)

| Workflow | Schedule | What it does |
|----------|----------|--------------|
| `feature_pipeline.yml` | Every hour | Fetches latest air quality data, uploads to Hopsworks Feature Store |
| `training_pipeline.yml` | Every day | Retrains all models, selects best, registers to Hopsworks Model Registry |
